========================================
图片批量删除工具 (1200x630)
========================================

========================================
推荐方案：PowerShell 版本（无需安装依赖）
========================================

文件：delete_1200x630.ps1

使用方法：
-----------
1. 右键点击 delete_1200x630.ps1，选择"使用 PowerShell 运行"
2. 或者在 PowerShell 中运行：
   .\delete_1200x630.ps1 -Directory "图片文件夹路径"

示例：
-----------
.\delete_1200x630.ps1 -Directory "C:\Pictures"

或者直接拖放文件夹到脚本文件上

========================================
Python 版本（需要安装 Pillow）
========================================

文件：delete_1200x630.py

安装依赖：
-----------
pip install Pillow

使用方法：
-----------
python delete_1200x630.py "图片文件夹路径"

========================================
打包的 EXE 版本（已包含 Pillow 依赖）
========================================

文件：
- dist\DeleteImages1200x630.exe (无控制台窗口)
- dist\DeleteImages1200x630_debug.exe (有控制台窗口，用于调试)

使用方法：
-----------
1. 双击运行 DeleteImages1200x630.exe
2. 将图片文件夹拖放到 exe 文件上
3. 或者命令行运行：DeleteImages1200x630.exe "图片文件夹路径"

注意：如果 EXE 版本运行报错，请使用 PowerShell 版本。

========================================
功能说明
========================================
- 自动检测指定目录下所有 1200x630 尺寸的图片
- 支持格式：JPG, JPEG, PNG, GIF, BMP, WEBP, TIFF, TIF
- 安全删除：先扫描显示所有匹配文件，然后批量删除
- 详细报告：显示检查数量、删除数量、保留数量

========================================
注意事项
========================================
- 删除操作不可恢复，请谨慎使用
- 建议先备份重要图片
- 默认检测尺寸为 1200x630，如需修改请编辑源代码
- PowerShell 版本需要 .NET Framework（Windows 自带）

========================================
文件清单
